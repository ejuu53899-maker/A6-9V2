# Contributing to GenX FX Trading System

We love your help! To make this project awesome, please follow these guidelines.

## Code of Conduct

This project and everyone participating in it is governed by a standard Code of Conduct. By participating, you are expected to uphold this code.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub issue tracker.
- Provide a clear, descriptive title.
- Include steps to reproduce the issue.

### Suggesting Improvements
- Clearly describe the proposed feature or improvement.
- Explain *why* it would be awesome and how users would benefit.

### Pull Requests
- Ensure your code is clean, documented, and follows the existing style.
- Include unit tests if applicable.
- Ensure your Pull Request is grammatically correct and typo-free.

## What is Awesome?

- **Curation, not Collection:** We only want to include actual awesome stuff.
- **Commentary:** Explain *why* a particular feature or tool is on the list.
- **Consistency:** Ensure descriptions are consistent (e.g., all sentences end in a period).
